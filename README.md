# SnipLink :  Full-Stack URL Shortener

A high-performance, lightweight URL shortener built with Python and FastAPI. This project provides a fully functional REST API for generating shortened links, alongside a responsive, zero-dependency vanilla frontend.

##  Features
* **Lightning Fast:** Powered by FastAPI and asynchronous Python.
* **Persistent Storage:** Uses SQLite and SQLAlchemy ORM to safely store URL mappings.
* **Algorithm-Driven:** Generates unique, collision-resistant 6-character alphanumeric aliases.
* **Clean UI:** A modern, responsive frontend built with Vanilla HTML/CSS/JS.

##  Tech Stash
* **Backend:** Python 3, FastAPI, Uvicorn, Pydantic
* **Database:** SQLite, SQLAlchemy
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
